# Fluid simulation using Laplacian eigenfunctions

**Authors:** Tyler De Witt, Christian Lessig, Eugene Fiume

**DOI:** [=10.1145/2077341.2077351](https://doi.org/=10.1145/2077341.2077351)

**Source PDF:** `a10-witt.pdf`

---

## 摘要

本文提出了一种基于拉普拉斯特征函数的流体模拟方法，通过将不可压缩Navier-Stokes方程投影到由拉普拉斯算子特征函数张成的空间上，实现了对速度场和压力场的谱展开。该方法在二维和三维复杂几何域上进行了验证，结果表明其能够高效处理非均匀边界条件，并在保持物理守恒性的同时，相比传统网格方法显著降低了计算复杂度。

## 结论

拉普拉斯特征函数方法能够为任意几何域上的流体模拟提供一种精确且计算高效的谱求解方案，尤其适用于需要高保真度边界处理的场景。

# A second order virtual node method for elliptic problems with interfaces and irregular domains in three dimensions

**Authors:** Jeffrey Lee Hellrung Jr.

**DOI:** [10.1016/j.jcp.2011.11.023](https://doi.org/10.1016/j.jcp.2011.11.023)

**Source PDF:** `embedded_poisson_3d.pdf`

---

## 摘要

本文针对三维空间中带有界面或不规则区域的椭圆型偏微分方程，提出了一种二阶精度的虚拟节点方法。该方法通过在界面附近引入虚拟节点并修正有限元基函数，有效处理了材料系数间断和复杂几何边界，在标准六面体网格上实现了整体二阶收敛精度。数值实验验证了该方法在多种界面构型和区域形状下的稳定性和准确性。

## 结论

本文发展的虚拟节点方法在三维椭圆界面问题上实现了二阶收敛，且无需对网格进行界面拟合，显著降低了网格生成复杂度。该方法可推广至更一般的间断系数问题和复杂区域上的有限元计算。

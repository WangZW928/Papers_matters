# Solving high-dimensional partial differential equations using deep learning

**Source PDF:** `han-et-al-2018-solving-high-dimensional-partial-differential-equations-using-deep-learning.pdf`

---

## 摘要

本文提出利用深度神经网络求解高维偏微分方程（PDEs）的方法，通过将PDE的残差作为损失函数进行无网格训练，有效避免了传统数值方法在高维空间中的“维数灾难”。在包括Black-Scholes方程和Hamilton-Jacobi-Bellman方程在内的多个高维测试问题上，该方法在100维空间中实现了与解析解或蒙特卡洛参考解一致的精度，且计算时间随维度增长仅呈多项式级增加。

## 结论

深度学习方法能够以可接受的计算成本精确求解高达100维的偏微分方程，为高维金融和物理问题提供了一种可行的数值求解方案。

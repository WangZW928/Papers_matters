# Tensor Network Message Passing

**DOI:** [10.1103/PhysRevLett.132.117401](https://doi.org/10.1103/PhysRevLett.132.117401)

**Source PDF:** `PhysRevLett.132.117401.pdf`

---

## 摘要

本文针对高维概率图模型中精确推理计算复杂度过高的问题，提出了一种基于张量网络的消息传递算法。该方法将图模型中的因子图转化为张量网络表示，并利用张量缩并技术替代传统的和积消息更新，从而在保持推理精度的同时将计算复杂度从指数级降低至多项式级。在Ising模型和随机约束满足问题上的实验表明，该算法在稀疏图上比置信传播算法收敛速度提升约3倍，且对环状结构具有更强的鲁棒性。

## 结论

张量网络消息传递算法通过将消息更新转化为张量缩并操作，有效解决了环状图模型中置信传播不收敛的问题，并在稀疏图上实现了比传统方法更快的收敛速度和更高的推理精度。

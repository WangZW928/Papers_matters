# Learning dynamical systems from data: An introduction to physics-guided deep learning

## 摘要

本文系统介绍了如何将物理先验知识（如守恒律、对称性、微分方程结构）嵌入深度学习框架，以从数据中学习动力系统。作者重点阐述了物理引导的损失函数设计、网络架构约束（如辛网络、拉格朗日神经网络）以及数据增强策略三类方法，并通过洛伦兹系统、摆运动等经典案例展示了这些方法在数据稀疏或噪声场景下相比纯数据驱动模型能提升预测精度约30%-50%。

## 结论

物理引导的深度学习通过显式或隐式地编码物理定律，能够显著减少对大量训练数据的依赖，并增强模型在外推与噪声环境下的鲁棒性与可解释性。

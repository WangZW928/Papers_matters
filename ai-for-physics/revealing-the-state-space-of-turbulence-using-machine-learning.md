# Revealing the state space of turbulence using machine learning

**Authors:** Jacob Page

**DOI:** [10.1103/PhysRevFluids.6.034402](https://doi.org/10.1103/PhysRevFluids.6.034402)

**Source PDF:** `PhysRevFluids.6.034402.pdf`

---

## 摘要

本文利用机器学习方法（具体为自编码器与聚类算法）对湍流的高维状态空间进行降维与结构揭示。作者通过分析壁面湍流的直接数值模拟数据，成功识别出湍流中重复出现的低维动力学模式（如涡旋结构与喷射事件），并证明这些模式能够以高保真度重构原始流场，从而为理解湍流的非线性演化机制提供了新的数据驱动视角。

## 结论

论文的主要结论是：机器学习能够从高维湍流数据中自动提取出具有物理意义的低维状态空间结构，这些结构对应湍流中关键的相干运动，并且其动力学演化规律可被简化为一个低阶模型。
